Product overview

A collection tool, not a digital game.

TCG VAULT focuses on card discovery and personal collection management. It does not simulate Riftbound gameplay or automate physical matches.

▦

Card library

Browse sets and cards, search by card information, and open detailed card pages.

✓

Owned collection

Track owned physical cards, quantities, supported finishes and collection completion.

⌕

Card scanning

Use the phone camera to help identify physical cards before confirming an addition to the collection.

↕

Filters & sorting

Sort cards by number, name, rarity, ownership and date added. Filter within sets and collections.

◫

Showcase

Collectors can select favorite cards for a personal showcase. Public profile features are being developed separately from Riot account data.

⌁

Local-first collection

Collection entries are stored locally during prototype testing, with optional account synchronization planned for later versions.

Riftbound integration

Intended Riftbound user flow.

The Riftbound module is implemented as a collection-library flow. Official card content and assets will only be loaded from Riot's API after the application receives the required API access.

01

Select Riftbound

The collector switches the active TCG to Riftbound from the app header.

02

Browse sets

The app loads the official Riftbound set/card catalogue supplied through Riot's API.

03

Open a card

The user sees official card information, art, text, rarity and supported properties.

04

Add owned copy

The collector records a physical copy and supported finish/variant in their personal collection.

05

Manage collection

Owned cards can be searched, sorted, counted and displayed in the user's personal collection.

Riot API & policy intent

Designed around authorized card-library use.

For Riftbound, the app is intended to consume only the content Riot makes available through the approved API integration.

Implementation commitments
✓Use Riot API-provided Riftbound card data and assets only.
✓Display official English card text or official translations when supplied by the API.
✓No simulated or replicated Riftbound gameplay.
✓No betting, gambling, matchmaking ladder or metagame win-rate/play-rate features.
✓Personal ownership information is separate from official Riot card content.
✓The product will not state or imply endorsement or sponsorship by Riot Games.
Project status

TCG VAULT is currently in private prototype testing. Riftbound API access is pending approval, so the public prototype shown here does not redistribute unofficial Riftbound card images or card text.

The intended API use is limited to a card library and collection-management experience for physical-card collectors.
